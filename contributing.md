## 🔧 Troubleshooting

| **Problem** | **Solution** |
|--------------|---------------|
| **Character drifts** | Add lock keywords |
| **Camera jitters** | Use dolly not handheld |
| **Lighting flat** | Add direction + source |
| **Motion blur too strong** | Lower shutter cue |
| **Prompt ignored** | Shorten and clarify |
| **Render fails** | Reduce duration |
